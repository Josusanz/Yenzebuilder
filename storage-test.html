📋 Setup Checklist

Step 1: Create Bucket

  1. Go to Supabase Storage
  2. Click "New bucket"
  3. Name: published-sites
  4. ✅ Check "Public bucket"
  5. Click "Create bucket"

Step 2: Configure Policies

  1. Go to SQL Editor
  2. Copy the SQL from supabase-storage-setup.sql
  3. Paste and run it
